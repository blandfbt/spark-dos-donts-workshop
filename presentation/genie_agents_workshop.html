The trust challenge

Natural-language analytics is only useful if people believe the answers
Sarah · marketing lead
“What was our click-through rate last quarter?”
Genie: 8.5%
“Wait, I remember celebrating when we hit 6% last quarter…”

Different campaigns? A standard calendar instead of the fiscal one? Sarah can't tell what went wrong, only that something feels off.

The real question

  • Not can Genie generate SQL, but do users trust the result enough to decide with it
  • Without systematic evaluation, doubt compounds
  • Users quietly go back to analysts, and the self-service investment sits unused

Start with clean, well-curated data

Table metadata is the most effective context

Choose focused datasets

A small, non-conflicting set of UC tables; remove columns users won't analyze

Use curated data

Gold tables, pre-aggregated views or metric views: fewer joins, simpler math, fewer tokens

Comments and synonyms

Describe every column with example values and the words business users say

Define relationships

Primary and foreign keys in Unity Catalog, or pre-join into views

©2026 Databricks Inc. — All rights reserved

Choose between tables and metric views

They serve different purposes in Genie

Metric views

  • Business metrics governed in Unity Catalog, defined once, reused everywhere
  • Deterministic by design; generated queries are simple to read
  • Group by any dimension: suits Genie's ad hoc nature
  • Trade-offs: you maintain the YAML; limited to the dimensions you add; KPIs not in the view can still be guessed

Tables

  • Simple to start and expand: add tables to an agent
  • Good for complex data models: Genie joins as needed
  • Needs the best practices: descriptions, PK/FK, expressions
  • Trade-offs: metrics live in instructions, examples and functions in one agent; less reusable and less deterministic
©2026 Databricks Inc. — All rights reserved

Select a focused topic and data

Curate in Unity Catalog, start small
Status as of Nov 2026
  • Aim for five or fewer tables: the narrower, the better
  • Hard limit: 50 tables, views or metric views per agent
  • One audience and one purpose per agent
  • Hide confusing or unused columns
  • Pre-join complex relationships into views or metric views
  • Think like the business: include only fields users analyze
  • Document everything: table and column descriptions
  • Have a domain expert build it: an SQL-proficient analyst
  • Start with the smallest setup, expand from feedback
©2026 Databricks Inc. — All rights reserved

Example SQL queries

Teach complete question-answering patterns
Status as of Nov 2026
  • A business question paired with its SQL; Genie reuses it or learns the pattern
  • Parameters (:region, typed String / Date / Decimal / …) make one example cover many questions
  • Usage guidance: say when the example applies
  • Trusted assets: parameterized examples and UC SQL functions return verified answers
  • Use them for complex, multi-part or ambiguous prompts
-- Question: What is net revenue for dealers in :state? SELECT ROUND(SUM(s.net_revenue), 2) AS net_revenue FROM lab_gold_daily_dealer_sales_fact s JOIN lab_silver_dealers_dim d USING (dealer_id) WHERE d.state = :state
©2026 Databricks Inc. — All rights reserved

Knowledge store: local data prep

Fix metadata inside the agent, without UC permissions
  • Hide columns that confuse Genie: no new view needed
  • Edit table and column descriptions locally; Reset restores UC
  • Column synonyms for cryptic names
  • Prompt matching: format assistance and entity matching (value dictionaries) for string columns
  • Changes stay in the agent; Unity Catalog metadata is untouched
©2026 Databricks Inc. — All rights reserved

Knowledge store: joins

Table relationships Genie doesn't have to guess
  • UC primary / foreign keys are saved as joins automatically
  • Define joins in the agent when you can't add keys, or relationships are complex
  • Set the relationship type: many-to-one, one-to-many, one-to-one
  • Suggested joins: Genie proposes joins it learns from conversations
  • Self-joins and multiple joins get aliases automatically
©2026 Databricks Inc. — All rights reserved

Knowledge store: measures

Exactly how to calculate a KPI
  • Aggregations that summarize data: total revenue, average order value, active customers, YoY growth
  • Name, SQL, synonyms and usage instructions
  • Genie retrieves the relevant ones per prompt
  • More knowledge in fewer tokens than example SQL or text
©2026 Databricks Inc. — All rights reserved

Knowledge store: fields (dimensions)

Row-level attributes to slice, filter and categorize
  • CASE WHEN …: categorize with if/then/else logic
  • CONCAT(a, '-', b): build a label
  • DATE_TRUNC('WEEK', order_date): date parts and buckets
  • DATEDIFF(…): days between two dates
  • COALESCE(col, 'Unknown'): null handling
©2026 Databricks Inc. — All rights reserved

Knowledge store: filters

Named conditions business users say out loud
  • Boolean conditions: large orders, active dealers, last fiscal quarter
  • One definition instead of every author re-typing the WHERE clause
  • Pair with synonyms: 'big deals' → the same filter
©2026 Databricks Inc. — All rights reserved

Knowledge store: suggestions from usage

Genie mines knowledge from feedback and metadata
  • When an author gives a 👍 or downloads results, Genie may suggest new SQL expressions and joins
  • Genie also analyzes Unity Catalog metadata for suggestions
  • Suggestions persist until an author reviews and saves them in the knowledge store
  • Nothing changes in the agent without an author's approval

The knowledge store, in priority order

Limits and what counts toward them
Status as of Nov 2026
UseForWhy
1 · SQL expressionsmetrics, filters, dimensionsstructured, reliable, cheap in tokens
2 · Example SQLcomplex, multi-part, ambiguousfull patterns Genie can reuse
3 · Text instructionswhat SQL can't sayglobal context, formatting, clarification
  • 200 knowledge-store snippets per agent: table descriptions, joins, SQL expressions
  • 100 instructions: each example SQL, each SQL function, and the text block count one each
  • Column descriptions, synonyms and prompt matching don't count
©2026 Databricks Inc. — All rights reserved

Finally, general instructions

Only when metadata, expressions or examples can't do it
DO
  • Teach when to ask for clarificationwhen a prompt is missing context
  • Add formatting rulesrounding, language, number of rows
  • Be concise and direct“When the user… make sure to…”, “Always include…”
  • Organize as a listeasier for collaborators and for Genie
  • Summariesunder the heading “Instructions you must follow when providing summaries”
DON'T
  • Overload the textit isn't filtered per prompt; it uses context in every question
  • Write conflicting rulestext says round to 2, examples must too
  • Enumerate column valuesuse prompt matching and value dictionaries
  • Put SQL logic in textuse SQL expressions and example SQL
©2026 Databricks Inc. — All rights reserved

Clarification questions: a four-part pattern

Place it at the end of the general instructions
01

Trigger condition

the topic or scenario: “When users ask about X…”

02

Missing details

what must be present: “…but don't include Y…”

03

Required action

“…you must ask a clarification question first”

04

Example question

the exact wording: “Please specify…”

“When users ask about sales performance breakdown [01] but don't include time range, sales channel or KPIs [02], you must ask a clarification question first [03]. For example: ‘Please specify the time range and sales channel you are looking for.’ [04]”

Genie benchmarks: what and why

Curated test questions with gold-standard answers
Status as of Nov 2026
  • Questions plus a SQL answer (or Generate SQL) and an optional evaluation note
  • Up to 500 benchmark questions per agent
  • Chat mode compares result sets with your SQL; Agent mode uses an LLM judge with the evaluation note
  • Run all benchmarks or Run selected; questions now run in parallel (Nov 2026)
  • Add any chat answer with ⋮ › Add as benchmark

Why

  • validate answers automatically
  • catch regressions after every change
  • show stakeholders measured accuracy before rollout
©2026 Databricks Inc. — All rights reserved

Reading benchmark results

Evaluations tab › select a run
Status as of Nov 2026
  • Resolve Manual review needed by comparing model output with ground truth, then marking Good or Bad
  • Per-question result data stays for one week; the generated and ground-truth SQL remain
  • Analyze with Genie: from a run, launch Genie Code to analyze it; it groups the failures, separates context gaps from questionable ground truth, and suggests instruction or context fixes for you to review and save

Genie rollout plan

Three stages, then repeat the last one

1 · Self-validation

  • Identify 10–20 key business questions and teach Genie to answer them
  • Benchmark them; test ad hoc questions yourself

2 · Staged rollout

  • A small group of trusted users first, then expand
  • Guide users: pair with a dashboard, sample questions, a short guide
  • Promote dev → prod with Declarative Automation Bundles

3 · Ongoing iteration

  • Monitoring tab and audit logs for prompts and feedback
  • Add to benchmarks, improve context, rerun benchmarks, repeat

Conversation API best practices

When you embed Genie in your own app
Status as of Nov 2026
  • Queue requests: the API doesn't retry for you; handle 429 with backoff
  • Poll adaptively: start every 1–5 s, back off to 60 s, stop after 10 min
  • Stop on a final status: COMPLETED, FAILED or CANCELLED
  • New conversation per user session; keep it for that session's follow-ups
  • Agent mode streams responses (Server-Sent Events) instead of polling
  • One backend poller per message, shared by all clients
